# Sales Forecast Uploader
I created this excel file to visualize sales history and forecasts for our demand planning team, and added functionality for them to update forecasts directly from the file. 

It lets you download sales and forecasts data for a given sales channel and other filters (product, category, etc) and then visualize that data in a line chart, edit the forecasts, and upload those changes to the database.

There is a neat conditional formatting feature on this page that highlights any forecast you changed so it’s easy to see if you did edit something, and what will be uploaded if you pressed the upload button.
